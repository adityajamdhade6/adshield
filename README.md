# AdShield

Fraudulent lead and ad-click detection.

## The problem

Ad fraud wastes real advertising spend: bots and click farms generate clicks and fake leads that
never become customers, yet the advertiser still pays for them and the campaign data gets
polluted. AdShield scores each click for fraud risk using the behaviour of its source IP (click
bursts, evenly spaced timing, repeated identical clicks, low-quality traffic sources), and explains
every score in terms a marketing manager can act on.

## Architecture

```
  raw click CSV  (ip, app, device, os, channel, click_time, is_attributed)
        |
        v
  data/loader.py ........ typed load + strict per-row validation, health report
        |
        v
  features/ ............. velocity | uniqueness | timing regularity | traffic-source risk
        |                (point-in-time: each click sees only earlier clicks)
        |
        +--------------------+---------------------+
        v                    v                     |
  models/rule_engine.py   models/classifier.py     |  time-ordered split, class weighting,
  named, weighted rules   XGBoost + SHAP           |  logged grid search, versioned artifacts
  (configs/rules.yaml)    (models/<version>/)      |
        |                    |                     |
        +---------+----------+---------------------+
                  v
        api/ (FastAPI) ......... /score  /score/batch  /health
          model score + rule score + SHAP contributions on every response;
          falls back to the rules if the model is missing or returns bad output
                  |
                  v
        dashboard/ (Streamlit) . upload CSV -> risk table, threshold slider, per-lead "why"
```

## Run it locally

Python 3.11+. From the repository root:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -e ".[dev]"
```

**Get the data.** Download `train.csv` from the Kaggle competition
[TalkingData AdTracking Fraud Detection](https://www.kaggle.com/competitions/talkingdata-adtracking-fraud-detection)
(a Kaggle account and accepting the competition rules are required) and place it at
`data/raw/train.csv`. It is about 7 GB and about 184M rows; `data/` is gitignored.

```bash
# 1. Validate the file and print a health report (use --nrows for a quick look)
python -m adshield.data.loader data/raw/train.csv --nrows 1000000

# 2. Rule-baseline evaluation on its own
python -m adshield.models.evaluate data/raw/train.csv --nrows 5000000

# 3. Train, evaluate on the held-out later period, write models/v1/ and reports/model_comparison.md
python -m adshield.models.classifier data/raw/train.csv --nrows 5000000 --version v1

# 4. Put the measured numbers into this README (replaces the Results block below)
python -m adshield.models.comparison models/v1/metrics.json --readme README.md
```

`--nrows` reads the first N rows, which cover only the start of the 4-day window; omit it for the
full file (needs several GB of RAM and a long validation pass).

Serve and explore:

```bash
# 5. API on http://localhost:8000  (docs at /docs)
ADSHIELD_MODEL_DIR=models/v1 uvicorn adshield.api.main:app --port 8000

# 6. In a second terminal: dashboard on http://localhost:8501
streamlit run src/adshield/dashboard/app.py
```

Score a click:

```bash
curl -s -X POST localhost:8000/score -H 'Content-Type: application/json' \
  -d '{"ip": 4242, "app": 12, "device": 1, "os": 13, "channel": 245, "click_time": "2017-11-07 09:30:00"}'
```

The dashboard has a built-in made-up example file, so you can try it before downloading anything.

## Limitations

- **The label is a proxy, not verified fraud.** `is_attributed == 0` only means a click never
  converted. Many honest clicks do not convert, and in this dataset most clicks do not. The model
  learns "looks like clicks that don't convert", which overlaps with fraud but is not the same
  thing. For that reason fraud-proxy precision and F1 look high for almost any system, and results
  are always shown next to a "flag every click" reference and as minority-class PR-AUC.
- **It only recognises patterns it was trained on.** It will not detect novel fraud that looks
  different from the training window (one 4-day period in November 2017), and it has no drift
  monitoring or retraining loop.
- **IP-centric.** Most signals are per-IP behaviour. Fraud that rotates IPs, or many honest users
  behind one shared IP (offices, mobile carriers), will mislead them.
- **Rule weights and thresholds were not fitted to data.** They are reasoned initial values in
  `configs/rules.yaml`, and the loader's categorical bounds are from the published file and should
  be confirmed on first load. The rule baseline is a floor to beat, not a tuned competitor.
- **Model scores are rankings, not calibrated probabilities** (class weighting shifts them). Use
  the saved threshold, not 0.5.
- **Training/serving skew in the API.** It keeps per-IP history in memory (24 h, bounded), so
  cumulative features cover only that window, history is lost on restart, and several workers do
  not share it. There is no authentication or rate limiting.
- **Label timing.** Conversions are only known some time after a click, so training labels near
  the train/validation boundary are slightly from the future. The split does not purge this.
- **Models are stored as pickles** with a checksum that catches accidental change, not
  deliberate tampering. Only load artifacts you trained.

## Layout

| Path | Purpose |
| --- | --- |
| `src/adshield/data/loader.py` | Typed CSV loader, strict per-row validation, health report |
| `src/adshield/features/engineering.py` | Velocity, uniqueness, regularity and risk-encoding features |
| `src/adshield/features/pipeline.py` | Fitted feature pipeline shared by training and serving |
| `src/adshield/models/rule_engine.py` | Deterministic, auditable rule scorer |
| `src/adshield/models/classifier.py` | Time-ordered split, XGBoost, grid search, SHAP, artifacts, rules fallback |
| `src/adshield/models/evaluate.py`, `comparison.py` | Metrics, the comparison report, README results |
| `src/adshield/api/` | FastAPI service |
| `src/adshield/dashboard/` | Streamlit review UI (with a made-up example CSV) |
| `configs/` | `model.yaml` (training), `rules.yaml` (rule weights and thresholds) |
| `notebooks/01_eda.ipynb` | Exploration only; production logic lives in `src/` |
| `models/`, `reports/` | Generated run artifacts and reports |

## Configuration

`configs/` is found relative to the source checkout; for any other install set
`ADSHIELD_CONFIG_DIR`. `ADSHIELD_MODEL_DIR` selects the model the API serves (a model you name
that fails to load aborts startup; with none found the API runs rules-only and `/health` reports
`degraded`). `ADSHIELD_API_URL` points the dashboard at the API.
